# Deploy the Streamlit studio

The app can run on Streamlit Community Cloud from the public GitHub repository. Select `app/app.py` as the entry point and use the repository root as the working directory. `requirements.txt` installs the package with app dependencies, and `.streamlit/config.toml` enables headless execution. The committed `examples/mnist_mlp.ng` file supplies the drawing demo without a training step on the server.

Before publishing, run locally:

```bash
python -m pip install -e ".[app,dev]"
python -m pytest -q
python -m streamlit run app/app.py
```

The rover and 2D views train small models during a session. They use CPU and session memory, so Community Cloud may take longer than a local machine. The MNIST view uses a loaded model and does not retrain. The research results in `docs/results/` are static artifacts generated by `python examples/study_navigation.py --seeds 10 --epochs 50`.

After publishing, add the live URL to the README and portfolio. Verify the first page loads, a short 2D training run completes, navigation can launch from that model, and a digit drawn in the MNIST canvas produces a prediction.
